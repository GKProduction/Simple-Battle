Установите эти шрифты, чтобы они внедрились в игру при компиляции. Чтобы шрифты внедрились, в игре должен быть включён режим отображения Direct3D 11.

==========

Install these fonts so that they are embedded into the game when compiled. The game must have Direct3D 11 display mode enabled for the fonts to be embedded.
